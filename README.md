# KairanKar Telegram Bot

Telegram-бот для флуда KairanKar: анкета одним сообщением, персональные ссылки-приглашения, база участников и управление занятыми/свободными ролями.

## Возможности

- Анкета одним сообщением: роль, кодовое слово, юзернейм.
- После анкеты бот создаёт персональную ссылку на одно вступление, действительную 24 часа.
- SQLite-база `kairankar.db`.
- Команды `/freeroles`, `/roles`, `/freerole`, `/addrole`, `/unfreerole`.
- Управление администраторами через `/adminadd` и `/adminremove`.
- Владелец по умолчанию: ID `7987275172`, username `durov2026_off`.
- Приветствие новых участников и упоминания пользователей, которых бот знает.

## Установка на Ubuntu / WSL

```bash
cd KairanKar_Bot
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
nano .env
```

Заполни `.env`:
- `BOT_TOKEN` — токен от @BotFather.
- `GROUP_ID` — числовой ID группы KairanKar, обычно начинается с `-100`.
Данные владельца уже встроены в `bot.py`:
- `OWNER_ID = 7987275172`
- `OWNER_USERNAME = "durov2026_off"`

Запуск:

```bash
python bot.py
```

## Настройка Telegram

1. Добавь бота в группу KairanKar.
2. Сделай его администратором.
3. Разреши боту приглашать пользователей (создавать invite links).
4. В @BotFather отключи Privacy Mode, если хочешь, чтобы бот видел обычные сообщения для дополнительных функций. Для текущих команд и событий входа это не обязательно.
5. Пользователь должен сам открыть бота и нажать `/start`, иначе бот не сможет написать ему в личку.

## Анкета

Пользователь отправляет боту `/start`, затем одним сообщением ровно три строки:

```text
Сяо
КодовоеСлово
@username
```

Кодовое слово сохраняется в локальной базе и не показывается в сообщении о приглашении. В этой версии оно собирается, но не сверяется с заранее заданным секретом.

## Команды в группе

### Для всех
- `/freeroles` — список свободных ролей.
- `/roles` — список занятых ролей.
- `/adminlist` — список администрации.
- `/here` — добавить себя в список пользователей, которых бот может упоминать.
- `/help` — справка.

### Для администраторов ролей
- `/addrole Имя персонажа` — добавить свободную роль.
- Ответь на сообщение пользователя: `/freerole Имя персонажа` — выдать роль.
- `/freerole @username Имя персонажа` — выдать роль пользователю, если он уже есть в базе.
- `/unfreerole Имя персонажа` — освободить роль.

### Только для OWNER
- Ответь на сообщение пользователя: `/adminadd` — выдать права администратора.
- Ответь на сообщение пользователя: `/adminremove` — снять права администратора.

Для назначения по username пользователь должен уже присутствовать в базе. Надёжнее использовать ответ на сообщение пользователя.

## Важные замечания

- Telegram не позволяет боту первым писать пользователю: пользователь должен сначала нажать `/start`.
- Бот не может автоматически получить полный список старых участников группы. Они могут выполнить `/here`, чтобы добавиться в список упоминаний.
- В сообщении при входе упоминаются только пользователи, которых бот знает.
- Кодовое слово хранится в SQLite как обычный текст. Не используй в качестве него пароль от других сервисов.
- Не публикуй файл `.env` и не отправляй токен бота посторонним.
- База данных создаётся автоматически при первом запуске.
